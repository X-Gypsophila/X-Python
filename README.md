# 离线记账工具（Python）

这是一个专为**离线环境**设计的极简记账 App：
- 仅使用 Python 标准库（`sqlite3`）
- 无需网络
- 无需第三方依赖
- 启动快、操作少

## 功能
- 新增收入/支出记录
- 自动汇总：总收入、总支出、结余
- 查看最近 10 条记录
- 本地 SQLite 持久化（`account_book.db`）

## 运行环境
- Python 3.10+

## 使用方法
```bash
python3 app.py
```

按提示输入数字进行操作：
- `1` 新增记账
- `2` 查看总览
- `3` 查看最近记录
- `0` 退出

## 设计说明
- 使用 SQLite 本地文件存储，适合断网或内网受限场景
- 使用命令行交互，避免额外框架复杂度
- 金额使用 `Decimal`，减少浮点误差
